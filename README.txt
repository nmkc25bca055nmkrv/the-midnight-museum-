THE MIDNIGHT MUSEUM — WEBSITE PROJECT
=====================================

FILES
-----
index.html  - Website content and HTML structure
style.css   - Colours, layout, typography, responsive design, and animations/effects
script.js   - Navigation, exhibit pop-ups, mystery quiz, and visitor pass form

HOW TO RUN
----------
1. Extract the ZIP file to a folder on your computer.
2. Open the folder in Visual Studio Code (VS Code).
3. Open index.html.
4. Right-click inside index.html and choose "Open with Live Server" if you have the Live Server extension.
   OR double-click index.html to open it directly in your browser.
5. Keep index.html, style.css, and script.js together in the same folder.

FEATURES
--------
- Responsive dark midnight-themed design
- Navigation links to page sections
- Four interactive exhibit detail pop-ups
- Mystery quiz with answer checking and a hidden Room 13 reveal
- Visitor pass form with a personalised confirmation
- Mobile navigation menu
- Accessible labels and feedback messages

IMPORTANT
---------
This is a fictional student project. The visitor pass form is a front-end demonstration only.
It does not save visitor data to a database or send it to a server.
The page uses Google Fonts from the internet; if unavailable, fallback fonts are used.

RUBRIC COVERAGE
---------------
1. Design and Layout: organised sections, colour palette, cards, responsive layout
2. HTML Structure and Content: semantic sections, headings, paragraphs, links, form, dialog
3. CSS Styling: custom fonts, spacing, colours, hover states, grid and mobile styling
4. Functionality: navigation, pop-up exhibit records, mystery quiz, visitor pass form
5. Originality and Completeness: fictional museum story, four exhibits, hidden room, footer
